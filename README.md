# open-eda-labs.github.io

Repositório central do laboratório open-eda-labs: workflows agênticos disparados por eventos, com Argo Workflows e padrões abertos.

| O que | Onde |
| --- | --- |
| Plano Mestre (decisões D-nn, etapas, riscos, perguntas) | [`docs/PLANO_MESTRE.md`](docs/PLANO_MESTRE.md) |
| Decisões de arquitetura tomadas depois do plano (ADRs) | [`docs/adr/`](docs/adr/README.md) |
| Progresso e próximo passo | [`PROGRESS.md`](PROGRESS.md) |
| Instruções para sessões de agente | [`CLAUDE.md`](CLAUDE.md) |
| Página do projeto (GitHub Pages) | [`index.html`](index.html), publicada em <https://open-eda-labs.github.io> |

A página é um único `index.html` sem build: componentes do [Astryx](https://github.com/meta/astryx) carregados por CDN em versão pinada, com fonte do sistema, modo escuro pelo sistema e alvos de toque de 44 px, seguindo as diretrizes de interface da Apple (ADR-0003).

As regras do laboratório valem para todos os repositórios e estão no [perfil da organização](https://github.com/open-eda-labs).
